# 📁 Файли бази даних myShop

Всі необхідні файли для відновлення та налаштування бази даних PostgreSQL.

---

## 📋 Список файлів у папці setupBd:

### 🗄️ SQL Скрипти

#### 1. **`database-schema.sql`** ⭐ ОСНОВНИЙ
- **Призначення:** Створення структури бази даних
- **Що містить:**
  - CREATE TABLE команди для всіх 5 таблиць
  - Foreign keys та constraints
  - Індекси для оптимізації
  - Коментарі та документацію
- **Коли використовувати:** ПЕРШИЙ крок після створення бази даних
- **Команда:**
  ```bash
  psql -U postgres -d myshop -f setupBd/database-schema.sql
  ```

#### 2. **`database-seed.sql`** 🌱 ТЕСТОВІ ДАНІ
- **Призначення:** Заповнення бази даних тестовими даними
- **Що містить:**
  - 4 користувачі (1 admin + 3 users)
  - 30 товарів (електроніка)
  - 4 замовлення
  - Order items
  - 16 product views для аналітики
- **Коли використовувати:** ПІСЛЯ виконання database-schema.sql
- **Команда:**
  ```bash
  psql -U postgres -d myshop -f setupBd/database-seed.sql
  ```

## 📊 Структура бази даних (короткий огляд):

```
myshop (Database)
├── users (Користувачі)
│   ├── id, login, password, is_admin, avatar
│   └── 4 тестові користувачі
│
├── products (Товари)
│   ├── id, name, image_url, price, discount, description
│   └── 30 тестових товарів
│
├── orders (Замовлення)
│   ├── id, user_id, order_date, status, payment_method, адреса
│   └── 4 тестові замовлення
│
├── order_items (Елементи замовлень)
│   ├── id, order_id, product_id, quantity
│   └── Зв'язує orders ↔ products
│
└── product_views (Перегляди для аналітики)
    ├── id, product_id, user_id, viewed_at, platform
    └── 16 тестових переглядів
```

## 🔧 Корисні команди:

### Перевірка підключення:
```bash
psql -U postgres -d myshop -c "SELECT COUNT(*) FROM products;"
```

### Перегляд таблиць:
```bash
psql -U postgres -d myshop -c "\dt"
```

### Скидання БД:
```bash
psql -U postgres -c "DROP DATABASE IF EXISTS myshop;"
psql -U postgres -c "CREATE DATABASE myshop;"
psql -U postgres -d myshop -f setupBd/database-schema.sql
psql -U postgres -d myshop -f setupBd/database-seed.sql
```

### Генерація JWT Secret:
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```
