# Опис функціоналу веб-застосунку MyShop

## 1. Загальна інформація про проект

**Назва проекту:** MyShop - Інтернет-магазин з системою аналітики

**Тип застосунку:** Full-stack веб-застосунок для електронної комерції

**Призначення:** Онлайн-платформа для продажу товарів з вбудованою системою аналітики для адміністраторів, що дозволяє відстежувати продажі, перегляди товарів, поведінку користувачів та прогнозувати майбутні показники.

---

## 2. Технологічний стек

### Frontend:
- **Next.js 15.2.4** - React-фреймворк для серверного рендерингу
- **React 19** - Бібліотека для побудови користувацьких інтерфейсів
- **TypeScript** - Статична типізація для JavaScript
- **Tailwind CSS 4** - Utility-first CSS фреймворк для стилізації
- **Redux Toolkit** - Керування глобальним станом застосунку
- **Framer Motion** - Анімації та переходи
- **React Hook Form** - Керування формами та валідація
- **Recharts** - Бібліотека для візуалізації даних та графіків

### Backend:
- **Next.js API Routes** - Серверні API endpoints
- **PostgreSQL** - Реляційна база даних
- **bcrypt** - Хешування паролів
- **jsonwebtoken (JWT)** - Аутентифікація користувачів

### Додаткові бібліотеки:
- **react-hot-toast** - Сповіщення користувача
- **lucide-react** - Іконки
- **pexels API** - Завантаження зображень товарів

## 3. Детальний опис сторінок та функціоналу

### 3.1. Головна сторінка (/)

**Файл:** `app/page.tsx`

**Призначення:** Відображення каталогу товарів з пагінацією

**Функціонал:**
- Відображення списку всіх доступних товарів у вигляді карток (grid layout)
- Адаптивна сітка товарів (1-4 колонки залежно від розміру екрану)
- Пагінація: 50 товарів на сторінку
- Серверний рендеринг (Server Component) для покращення SEO та швидкості завантаження
- Отримання даних з PostgreSQL бази даних через функції `getProducts()` та `getProductsCount()`

**Компоненти, що використовуються:**
- `ProductCard` - Картка товару
- `PaginationWithLinks` - Навігація по сторінкам

**UI/UX особливості:**
- Чистий, мінімалістичний дизайн
- Центрований заголовок "Our Products"
- Рівномірні відступи між картками товарів
- Навігація пагінації внизу сторінки

### 3.2. Сторінка авторизації (/auth)

- Автоматичне перенаправлення на головну сторінку після входу
- Посилання на сторінку реєстрації

**Технічні особливості:**
- Використання `react-hook-form` для керування формою
- Анімований gradient-ефект на тексті та обводці форми (Framer Motion)
- Обробка помилок та відображення повідомлень про помилки
- Credentials: include для збереження cookies

**UI/UX особливості:**
- Центрована форма на весь екран
- Темний фон з неоновим зеленим акцентом (#1cca50)
- Анімована обводка форми (rotating gradient)

  - Місто
  - Вулиця

**Бізнес-логіка:**
- Розрахунок ціни з урахуванням знижок: `price * (1 - discount/100) * quantity`

## 5. API Endpoints

### 5.1. POST /api/login
**Файл:** `app/api/login/route.ts`

**Призначення:** Авторизація користувача

**Вхідні дані:**
```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

**Вихідні дані (успіх):**
```json
{
  "user": {
    "id": 1,
    "email": "user@example.com",
    "is_admin": false
  }
}
```

**Логіка:**
- Перевірка email та пароля в базі даних
- Порівняння хешованого пароля через bcrypt
- Генерація JWT токену
- Встановлення cookie з токеном
- Повернення даних користувача

---

### 5.2. POST /api/register
**Файл:** `app/api/register/route.ts`

**Призначення:** Реєстрація нового користувача

**Вхідні дані:**
```json
{
  "email": "newuser@example.com",
  "password": "password123"
}
```

**Логіка:**
- Перевірка, чи email вже існує
- Хешування пароля через bcrypt
- Створення нового користувача в БД
- Генерація JWT токену
- Автоматична авторизація
- Повернення даних користувача

---

### 5.3. POST /api/logout
**Файл:** `app/api/logout/route.ts`

**Призначення:** Вихід з системи

**Логіка:**
- Видалення JWT токену з cookies
- Очищення сесії

---

### 5.4. GET /api/orders
**Файл:** `app/api/orders/route.ts`

**Призначення:** Отримання списку замовлень

## 6. База даних

### Структура таблиць:

#### users
- `id` - первинний ключ
- `email` - електронна пошта (унікальна)
- `password_hash` - хешований пароль
- `is_admin` - прапорець адміністратора
- `created_at` - дата реєстрації

#### products
- `id` - первинний ключ
- `name` - назва товару
- `description` - опис
- `price` - ціна
- `discount` - знижка в %
- `image_url` - URL зображення
- `stock_quantity` - кількість на складі
- `created_at` - дата додавання

#### orders
- `id` - первинний ключ
- `user_id` - зовнішній ключ на users
- `order_date` - дата замовлення
- `status` - статус (pending, processing, completed, cancelled)
- `payment_method` - спосіб оплати
- `total_amount` - загальна сума
- `city`, `street`, `house_number`, `postal_code` - адреса доставки

#### order_items
- `id` - первинний ключ
- `order_id` - зовнішній ключ на orders
- `product_id` - зовнішній ключ на products
- `quantity` - кількість
- `price_at_purchase` - ціна на момент покупки

#### product_views
- `id` - первинний ключ
- `product_id` - зовнішній ключ на products
- `user_id` - зовнішній ключ на users (nullable)
- `viewed_at` - дата та час перегляду
- `platform` - платформа (web, android, ios)
